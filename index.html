ARCHIVE OS

기록의 틈 스튜디오 컨트롤 센터

ARCHIVE OS는 YouTube 채널 「기록의 틈」 운영자가 자기 PC에서만 쓰는 데스크톱 대시보드입니다. 업로드 일정, 제작 중인 회차, 할 일, 채널 성과를 한 화면에 모아 봅니다.

YouTube 데이터 사용

운영자가 직접 연결하면 YouTube Data API와 YouTube Analytics API에서 운영자 본인 채널의 영상 목록, 조회수, 구독자 수, 분석 지표를 읽어 옵니다. 읽기 전용 권한만 요청하며 영상 업로드, 수정, 삭제는 하지 않습니다.

English summary

ARCHIVE OS is a private desktop dashboard used only by the operator of the YouTube channel “기록의 틈” on their own computer. With the operator's consent it reads their own channel data through read-only YouTube Data API and YouTube Analytics API scopes. It never uploads, edits or deletes anything on YouTube.
