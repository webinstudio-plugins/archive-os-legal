개인정보처리방침

ARCHIVE OS · 시행일 2026년 11월 24일

1. 누가 쓰는 앱인가

ARCHIVE OS는 YouTube 채널 「기록의 틈」 운영자가 자기 PC에서만 실행하는 개인용 데스크톱 앱입니다. 일반 사용자에게 배포하거나 판매하지 않습니다.

2. 읽어 오는 정보

운영자가 Google 계정으로 직접 승인하면 아래 읽기 전용 권한으로 운영자 본인 채널의 정보만 읽습니다.

  • youtube.readonly: 채널 정보, 구독자 수, 업로드 영상 목록과 공개 상태, 조회수·좋아요·댓글 수
  • yt-analytics.readonly: 일별 조회수, 시청 시간, 구독 증감
  • yt-analytics-monetary.readonly: 일별 예상 수익

영상 업로드, 수정, 삭제, 예약 변경 같은 쓰기 요청은 하지 않습니다.

3. 저장과 보관

받은 정보와 로그인 토큰은 운영자 PC의 로컬 파일에만 저장합니다. 외부 서버로 보내지 않고, 제3자에게 제공하거나 판매하지 않으며, 광고에 쓰지 않습니다.

4. 연결 해제와 삭제

앱 설정에서 연결을 해제하면 로컬 토큰 파일이 지워집니다. Google 계정의 타사 액세스 관리에서도 언제든 권한을 취소할 수 있습니다.

5. Google API 데이터 정책

ARCHIVE OS가 Google API에서 받은 정보를 사용하고 다른 앱으로 옮기는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

English summary

ARCHIVE OS is a personal desktop app run only by the operator of the YouTube channel “기록의 틈”. With the operator's consent it reads that channel's data through read-only scopes (youtube.readonly, yt-analytics.readonly, yt-analytics-monetary.readonly). Data and tokens are stored only on the operator's own computer, are never sent to any server, shared, sold or used for advertising. Access can be revoked at any time in the app settings or at myaccount.google.com/permissions. ARCHIVE OS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
